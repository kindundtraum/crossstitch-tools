# Скрипт для генерации 3D-моделей заготовок

Создано с использованием Deepseek

## Требования

Python 3.12.1 - версия, на которой тестировался скрипт конвертации матриц

OpenSCAD - для рендера модели и генерации .3mf

## Использование

1. В файл [crosses_to_holes.py] вносим матрицу крестиков и запускаем. Скрипт переведёт крестики в "дырочки"
2. В файл embroidery_form.scad переносим полученную матрицу "дырочек". Если нужно, можно добавить подвес:
    1. Одиночная 2 - подвес выровнен с остальным дырочками
    2. Две 2 подряд - ответстие подвеса между двух дырочек
